❓ User Guide

1. Setting Up the Control Panel

Before using the panel, load your rota names and appliances via Settings.

1
IC Entries (Rota Names)
Open Settings → IC Entries → Quick import…
Copy the contents of Ops Log Rota Names List.txt and paste it into the import box, then click Import.
2
Appliances
Open Settings → Appliances → Quick import…
Copy the contents of Ops Log Alpha List.txt and paste it into the import box, then click Import.
💾 Note: These settings are saved in your browser and will not be erased when you refresh the page.

2. Setting Up the VBA Code in Excel

The VBA macro needs to be loaded into Excel once.

1
Open the Ops Log Excel file and go to the Ops Log tab.
2
Press Alt + F11 to open the VBA editor.
3
Press Ctrl + M to import a module, then select the file Open this in VBA.bas.
4
Close the VBA editor. The macro is now ready.
⚠️ Note: The loaded VBA module is not permanently saved in the Excel file. Every time the Ops Log Excel file is closed and reopened, you will need to repeat steps 2–4 to reload the macro.

3. Workflow — Generating an Ops Log

1
(Night shift only) Complete the REDCON email first, then paste it into the REDCON Alpha section of this panel.
2
Select the Current IC and Incoming IC, set the shift mode, and fill in any P3 details if applicable.
3
Click Copy Code to Clipboard. The code is now in your clipboard.
4
Switch to Excel and press Alt + F8, select GenerateFromClipboard, then click Run (or press Enter).
5
Excel reads the code from the clipboard and automatically generates the ops log below the previous entry.

4. Settings Options

  • Add a name — type a rank and name in the fields at the bottom of IC Entries and click + Add. Use the rota tabs (Rota 1 / 2 / 3) to target the correct rota.
  • Edit a name — click the ✎ pencil icon on any entry, update the fields, and click Save.
  • Remove a name — click the ✕ button on the entry.
  • Reorder names — drag the ⠿ handle on any entry to move it up or down. The order here controls the order of the name buttons on the main panel.
  • Add / remove appliances — use the Appliances section. Adding or removing an appliance here immediately affects which callsigns appear in the generated night-shift ops log.

5. Troubleshooting

❝ No names loaded for Rota _. Check Settings. ❞

The IC name data for that rota has been cleared (e.g. browser data was wiped). Follow Section 1 to re-import the names.

❝ Pressing Alt+F8 does not show the GenerateFromClipboard macro. ❞

The VBA module has not been loaded into Excel yet, or was unloaded when the file was closed. Follow Section 2 to load it again.

RDR Report

6. Setting Up RDR Name Lists

OPS and EMS OH name lists are configured in Settings. AM/PM Rota names are pulled automatically from the IC Entries you already configured above.

1
Open Settings, scroll to RDR Report — OPS Names and add all OPS Readiness names, or use Quick import….
2
Repeat for EMS Names.
3
The AM Rota and PM Rota columns are automatically derived from the IC Entries based on the report date — no separate configuration needed.

7. Generating an RDR Email

1
Switch to the RDR Report tab and set the report date, shift type, and day type.
2
Paste each rollcall message into the matching box. The date and statuses are auto-detected.
3
Review the attendance grid. Adjust any statuses manually if needed.
4
Click Copy RDR Code to Clipboard, then in Outlook press Alt+F8 and run GenerateRDREmail.
